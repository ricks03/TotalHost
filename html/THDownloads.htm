Downloads

These are a few items that I use the most commonly.

Stars! Unofficial Release

  • Stars! 2.6k (the decompiled/recompiled version for Win x 64) (.zip)
  • Stars! 2.6k Linux (the decompiled/reconpiled version for Linux (host only) (/tar/gz)

Stars! Official Releases:

  • Stars! English Demo for 2.6b (.zip)
  • Stars! 2.6jrc4 (requires license key) (.zip)
  • Strategy Guide Framed Version (.zip)
  • Strategy Guide Non-framed Version (.zip)
Note: You can also view the the Strategy Guide on TotalHost.

TotalHost Client:

  • THClient (.exe)
    Downloads your new turns automatically and uploads your turn as soon as you save it in Stars!. Windows; nothing else to install.
  • thclient.conf.example
    Settings file: copy to thclient.conf in the same folder and fill in your login and games.
  • Setup instructions (.txt)
  • thclient.pl
    The Perl script the .exe is built from, for Linux/macOS or to build your own.

Utilities:

  • Stars! Calculator v3.06 (.zip)
    A great utility for calculating packet damage, player scores, fuel consumption, etc. (.zip)
  • Stars Xprt (.zip)
    Another Stars! calculator
  • Starstat Turn Utility 1.04c (.zip)
    Command line utility to display information about any particular Stars! file. (.exe)
  • Starmap 2.0 (.zip)
    Display multiple players data
  • XTreme Borders 1.71 (.zip)
    Display multiple players data
Compatibility:
  • Run Stars! under DOSBox in 64-bit zip or rar (must also install DOSBox, see instructions)
